# Kola

**Kola is an AI voice agent for Nigerian customer service.** It calls customers and answers their calls in
Nigerian English, Pidgin, Yoruba, Igbo and Hausa: order updates, payment follow-ups, appointment reminders,
bank safety checks and everyday questions. Businesses set the hours Kola calls; it can work around the clock.

Built by **KOLAPPTECH LTD** (RC 9945011), Nigeria.

| Product | For | Live |
|---|---|---|
| **Kola for Banks** | Banks and fintechs: customer calls through the bank's own API, with Kola Desk for hand-over to staff | [kolapp.tech](https://kolapp.tech) |
| **Kola for Business** | Shops, schools and services: orders, payments, bookings and customer care, set up without code | [business.kolapp.tech](https://business.kolapp.tech) |
| **Kola Voices** | Developers: our own Nigerian voices and speech recognition, by API | [voices.kolapp.tech](https://voices.kolapp.tech) |

All three share one Kola account and one voice engine. Kola never guesses: an order's status or a balance is
only ever what the business or bank has set.
